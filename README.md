# ZephyrLedger

Maintains a digital record of all changes made to code and related project metadata in a centralized repository.

With ZephyrLedger, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/ZephyrLedger.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure ZephyrLedger, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
